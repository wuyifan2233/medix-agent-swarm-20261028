# 本地管理员后台

入口：`http://127.0.0.1:8765/admin`。管理员登录后，左下角账号菜单显示“管理后台”。普通账号无法访问页面和接口。

## 指定管理员

先通过手机号正常注册账号，再在项目目录执行：

```powershell
.\.venv-auth\Scripts\python.exe scripts/set_admin.py --phone 你的已注册手机号
```

命令保留用户 ID、密码和关联资料，撤销已有登录会话，重新登录后生效。管理员身份不由注册请求或前端指定。

## 支持的功能

- 真实用户总数、正常账号、停用账号、管理员数量。
- 按显示名或手机号搜索，分页查看账号信息，手机号仅脱敏展示。
- 停用、恢复普通账号；停用立即撤销该用户已有会话。
- 管理员不能通过此接口停用管理员账号。

不提供私人病历、私人知识库、记忆内容的查看功能，也没有未接入模块的占位统计。未绑定手机号账号的管理员密码重置工具仍在待办。
